# Personality Assessment Architecture

## Hierarchy

DOMAIN
-> ASPECT
-> FACET
-> EXPRESSION
-> RECONCILIATION

## Locked Principles

1. Domains are organizational summaries.
2. Domains are not directly tested.
3. Aspects are the primary testing units.
4. Domains emerge from aspect aggregation.
5. Facets are explanatory mechanisms.
6. Expressions are behavioral evidence.
7. Reconciliation explains contradictions.
8. Three-pass assessment is required.
9. Variance is meaningful information.

## Assessment Flow

Aspect Assessment -> Aspect Score -> Facet Validation -> Expression Validation -> Reconciliation -> Identity Map
