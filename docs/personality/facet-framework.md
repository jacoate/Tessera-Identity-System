# Facet Framework

## Definition
A facet is a structural expression channel through which an aspect manifests behaviorally.

## Purpose
Facets answer: 'What kind of this aspect exists?'

## Roles
- Explanation of aspect scores
- Differentiation between individuals with similar aspect scores
- Routing to relevant expression cards

## Example
Assertiveness
- Leadership
- Initiative
- Influence
- Verbal Confidence

Facets are interpretation instruments rather than full psychometric inventories.
