# Expression Validation Model

Expressions are observable behavioral evidence.

## Definition
An expression is a specific behavior that provides evidence for a facet.

## Function
Expressions validate, challenge, or refine facet interpretations.

## Example
Leadership
- Organizes groups
- Delegates tasks
- Coordinates efforts
- Resolves indecision

## Validation Scales
Frequency:
- Never
- Rarely
- Sometimes
- Often
- Consistently

Identification:
- Not Me
- Somewhat Me
- Mostly Me
- Definitely Me
