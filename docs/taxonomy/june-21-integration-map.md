# June 21 Taxonomy Integration Map

Version: 0.1 Provisional  
Status: Active / Provisional / Source Integration  
Scope: Tessera card-based Personality / Karma model only

---

## Purpose

This document integrates the June 21 taxonomy-decision archive into the current ten-aspect Tessera personality taxonomy.

The June 21 file is valuable as a source of candidate facets, semantic distinctions, and reassignment decisions. It should not be treated as an active competing aspect schema.

Current active aspect architecture remains:

```text
Extraversion
- Assertiveness
- Enthusiasm

Agreeableness
- Compassion
- Politeness

Conscientiousness
- Industriousness
- Orderliness

Negative Emotionality / Neuroticism
- Withdrawal
- Volatility

Openness / Intellect
- Openness
- Intellect
```

---

## Overwrite / Integration Notice

This document supersedes the June 21 eight-aspect list as active taxonomy infrastructure.

The following June 21 aspects are no longer active aspect-schema anchors:

```text
Agency
Social Vitality
Communion
Self-Regulation
Emotional Stability
Exploration
Honesty
Reflection
```

They are reclassified as candidate-source clusters, facet-generation material, reconciliation context, symbol-context material, or future module material.

This integration does not delete useful June 21 material. It prevents the older eight-aspect structure from being mistaken for the active schema in manual drafting, card drafting, or future digital implementation.

---

## Integration Rule

A June 21 construct may be retained when it:

- improves expression-level precision;
- can produce distinct observable expressions;
- does not duplicate an active aspect;
- does not duplicate a Karma dimension;
- does not convert personality response into moral judgment;
- is labeled as candidate or source-lineage material when speculative;
- preserves empirically supported source information rather than replacing it.

A June 21 construct should not be retained as an active aspect merely because it is semantically useful. Semantic usefulness may justify a candidate facet, expression cue, symbol theme, or reconciliation route instead.

## Detailed Integration by Active Aspect

### Assertiveness

Source clusters:

```text
Agency
```

Candidate material retained:

- leadership;
- initiative;
- influence;
- visibility / presence;
- courage, when framed as directiveness under cost rather than moral virtue;
- self-efficacy, when framed as confidence in action rather than global self-worth.

Boundary notes:

- Perseverance and achievement should usually route to Industriousness.
- Courage should not automatically become Karma / Moral Courage unless moral cost, harm, consequence, or ethical risk is present.

### Enthusiasm

Source clusters:

```text
Social Vitality
```

Candidate material retained:

- sociability;
- humor;
- playfulness;
- positive affect;
- affability;
- social participation;
- social stamina;
- personal disclosure, if framed as expressive openness rather than honesty or vulnerability disclosure.

Boundary notes:

- Warmth may route to Compassion when it functions as relational receptivity.
- Social Stamina is useful but should be tested for distinction from general sociability and extraverted energy.

### Compassion

Source clusters:

```text
Communion
```

Candidate material retained:

- compassion;
- trust, if framed as relational expectation rather than gullibility or moral judgment;
- cooperation, when framed as affiliative coordination;
- protectiveness;
- warmth.

Boundary notes:

- Fairness and altruism should not be automatically placed here if they imply ethical evaluation. They may belong to Karma or symbol/reconciliation context.
- Personality Compassion measures responsiveness to need; Karma evaluates ethical action under cost, power, harm, accountability, or consequence.

### Politeness

Source clusters:

```text
Communion
Agency contrast material
```

Candidate material retained:

- conflict restraint;
- boundary respect;
- non-intrusiveness;
- deference calibration;
- civility;
- dominance restraint.

Boundary notes:

- Politeness is not moral goodness.
- High politeness may support care, avoidance, social conformity, impression management, or role suppression depending on context.

### Industriousness

Source clusters:

```text
Agency
Self-Regulation
```

Candidate material retained:

- achievement orientation;
- perseverance;
- self-discipline;
- persistence;
- task activation;
- productive endurance;
- reliability;
- attention control when tied to sustained effort.

Boundary notes:

- Reliability describes behavioral follow-through, not moral honor by itself.
- Responsibility under moral consequence routes to Karma / Accountability Orientation.

### Orderliness

Source clusters:

```text
Self-Regulation
```

Candidate material retained:

- organization;
- planning;
- prudence, when framed as structure and risk forecasting rather than moral wisdom;
- deliberation;
- detail consciousness;
- rule consistency;
- environmental order.

Boundary notes:

- Prudence may later need review because it can overlap with self-regulation, future orientation, risk sensitivity, and Karma-relevant consequence awareness.

### Withdrawal

Source clusters:

```text
Emotional Stability
Security
Attachment Security as source material
```

Candidate material retained:

- anxious anticipation;
- avoidant retraction;
- self-consciousness;
- vulnerability;
- ruminative concern;
- security seeking;
- threat sensitivity.

Boundary notes:

- Attachment-specific interpretation should be deferred to future object-relations or attachment modules unless card wording remains strictly personality-expression focused.

### Volatility

Source clusters:

```text
Emotional Stability
```

Candidate material retained:

- irritability;
- anger reactivity;
- emotional escalation;
- impulsive expression;
- conflict activation;
- recovery difficulty;
- low emotional threshold.

Boundary notes:

- Volatility is not a moral defect.
- Karma becomes relevant only when emotional activation intersects with harm, coercion, accountability, intent, or consequence.

### Openness

Source clusters:

```text
Exploration
Reflection candidate material
```

Candidate material retained:

- aesthetic appreciation;
- imagination;
- creativity, when experiential or expressive rather than technical problem solving;
- novelty seeking / novelty receptivity;
- tolerance for ambiguity, when experiential or interpretive;
- experimentation;
- meaning-making.

Boundary notes:

- Meaning-making may overlap with Reflection and identity. Keep it as Openness only when it describes experiential-symbolic interpretation rather than self-evaluation architecture.

### Intellect

Source clusters:

```text
Exploration
Reflection candidate material
```

Candidate material retained:

- inquisitiveness;
- abstract thinking;
- need for cognition;
- analytical curiosity;
- problem structuring;
- belief examination;
- cognitive flexibility;
- metacognition, if framed as thought-process monitoring rather than identity development.

Boundary notes:

- Intellect should not imply intelligence score or cognitive ability. It refers to engagement with ideas, reasoning, systems, and conceptual complexity.
- Reflection-related material should remain candidate-only until the model decides whether self-analysis belongs inside the personality taxonomy or in a separate identity/reconciliation layer.

## Honesty / Honesty-Humility Handling

Honesty from the June 21 file is not retained as an active aspect.

Its source material is routed as follows:

| June 21 material | Current handling |
|---|---|
| Truthfulness | Karma / Authentic Presentation; Disclosure symbol; question wording if neutral |
| Transparency | Disclosure symbol; Karma / Authentic Presentation when ethically activated |
| Reciprocity | Karma / Relational Equity; Equity symbol |
| Authentic Communication | Disclosure symbol; possible expression wording under Assertiveness or Politeness depending on function |
| Sincerity | Karma / Authentic Presentation |
| Fairness | Karma / Relational Equity |
| Honor | Karma / Accountability or Constraint Internalization when ethical; Reliability expression when behavioral follow-through |
| Promise Keeping | Expression under Reliability or Karma-relevant accountability depending on context |

Rule:

```text
Honesty-derived material may provide context.
It should not become a separate personality score unless later review identifies a distinct nonredundant behavioral function not covered by active aspects, Karma, symbols, or reconciliation.
```

## Reflection Handling

Reflection from the June 21 file is not retained as a primary aspect in the current card-based personality taxonomy.

It is preserved as candidate material for:

- reconciliation review;
- identity-map interpretation;
- development orientation;
- future self/identity modules;
- possible Intellect facets when the content concerns cognitive review rather than identity coherence.

Candidate material includes:

- introspection;
- extrospection;
- self-knowledge;
- perspective taking;
- metacognition;
- meaning-making;
- identity coherence;
- self-evaluation;
- belief examination;
- cognitive flexibility.

Boundary rule:

```text
Do not treat Reflection as an active personality aspect until the model determines whether self-analysis is a trait-like disposition, a reconciliation skill, an identity-process layer, or a later development module.
```

## Testing Model Integration

The June 21 archive did not define a complete aspect-questioning method. Its primary value is taxonomy reasoning and candidate facet material.

The active testing model remains the current aspect-questioning model:

```text
Aspect deck
-> varied question family
-> response sort
-> full pattern review
-> derived marker
-> behavioral consistency / directiveness interpretation
-> possible symbol context
-> reconciliation cue
```

Question-family types remain:

- core tendency;
- motivation / preference;
- behavioral tendency;
- threshold / activation;
- inhibition / suppression;
- context variation;
- reverse / contrast items.

Markers should be derived from the completed response pattern rather than self-certified by the participant.

## Future Digital Schema Guidance

Future digital implementation should not ingest the June 21 eight-aspect list as active schema.

Recommended treatment:

```text
june21.cluster = source_lineage
june21.facet_candidate = candidate_source_material
personality.aspect = current ten-aspect anchor
personality.candidate_facet = current mapped facet candidate
karma.dimension = moral-context interpretation dimension
symbol.context_marker = non-scoring reference marker
validation_status = provisional / source-derived / empirically reviewed / validated
```

Digital systems should preserve the difference between:

- empirical source constructs;
- Tessera-specific speculative candidates;
- entertainment mechanics;
- official validated assessment claims.
