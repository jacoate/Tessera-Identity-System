# Taxonomy and Karma Boundary

## Status

This document describes the current provisional boundary between the personality taxonomy and the Karma model.

The boundary remains open to review. It should be revised if future analysis shows redundancy, missing construct coverage, or inaccurate separation.

## Core Separation

The personality taxonomy and Karma model serve different functions.

```text
Personality Taxonomy
= describes dispositional tendencies, expression patterns, contextual variability, and behavioral evidence.

Karma Model
= examines ethical meaning under tradeoff, cost, power, concealment, harm, accountability, consequence, or moral conflict.
```

Personality responses should not be used by themselves to infer moral character.

Karma responses should not be reduced to personality traits.

## Honesty-Humility Status

Honesty-Humility is not currently retained as an active taxonomy domain or scored bridge.

The current working interpretation is that its central moral content is represented more precisely by Karma dimensions:

| Honesty-Humility Source Content | Karma Representation |
|---|---|
| sincerity | Authentic Presentation |
| fairness / exploitation avoidance | Relational Equity |
| modesty / entitlement restraint | Self-Regard Calibration |
| greed-avoidance / material detachment | Material Orientation |

If later review identifies nonredundant behavioral content from Honesty-Humility that is not represented by the taxonomy, Karma, symbols, or reconciliation process, that content may be proposed for inclusion. The proposal should follow the overwrite policy.

## Neutral Behavioral Residue

Some Honesty-Humility-derived material may be useful outside direct moral interpretation. Examples include:

- plain self-presentation;
- low image-management tendency;
- low status appetite;
- resource restraint;
- reciprocity preference;
- discomfort with manipulation;
- non-exploitative interaction style.

These should not become a separate Honesty-Humility score by default.

They may be used as:

- neutral question wording;
- symbol tags;
- reconciliation context;
- Karma source-lineage notes;
- manual examples.

## Overlap Safeguard

If a construct appears in both systems, the function must be distinguished.

Example: Compassion

```text
Taxonomy Compassion:
General tendency to notice and respond to others' needs or distress.

Karma Compassion / Affective Empathy:
Ethical significance of care, callousness, harm awareness, or responsiveness under morally relevant conditions.
```

A taxonomy card might ask whether the person notices distress.

A Karma card might ask whether the person accepts cost, risk, accountability, or consequence to respond to distress.

These should not be interpreted as the same measurement.

## Communication Between Systems

The taxonomy and Karma model may communicate through neutral symbols and reconciliation review.

They should not communicate through automatic score conversion.

Preferred structure:

```text
Taxonomy card response
→ optional neutral symbol context
→ possible reconciliation relevance
→ possible Karma context if later scenario activates the same theme
```

Avoid:

```text
Taxonomy score
→ moral score conversion
→ Karma result
```

## Analog Constraint

Because Tessera is currently an analog card-based model, the boundary between systems should be readable through card design, printed symbols, sorting outcomes, reference charts, and manual procedures.

The system should not require hidden digital calculation or database lookup to preserve the distinction between taxonomy and Karma.
