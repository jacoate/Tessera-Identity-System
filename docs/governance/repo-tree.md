# Repository Tree

## Status

This file is the repository tree governance index for the Tessera Identity System.

## Important Access Note

This file was created through connector-accessible known-file operations. At creation time, the connector did **not** expose a reliable recursive repository-tree enumeration function. Therefore, the initial tree below should be treated as a connector-known governance tree, not a verified full repository tree.

A GitHub Actions workflow is being added at `.github/workflows/update-repo-tree.yml` to regenerate this file using `git ls-tree -r --name-only HEAD` from inside the repository. Once that workflow runs successfully, this file can serve as a full Git-derived repository tree.
